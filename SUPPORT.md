# Support

This repository is maintained by a small team. The routes below help us respond
without putting security-sensitive information in public.

## Choose the right channel

| Need | Channel |
|---|---|
| Usage question or design discussion | [GitHub Discussions](https://github.com/identark/identark-cli/discussions) |
| Reproducible CLI bug | [GitHub Issues](https://github.com/identark/identark-cli/issues/new/choose) |
| Feature proposal | [GitHub Issues](https://github.com/identark/identark-cli/issues/new/choose) |
| Security vulnerability | [security@identark.io](mailto:security@identark.io) |
| Code of Conduct report | [conduct@identark.io](mailto:conduct@identark.io) |
| Commercial support | [enterprise@identark.io](mailto:enterprise@identark.io) |

Never post credentials, session tokens, customer data, private service details,
or unredacted logs in an issue or discussion. If a maintainer needs additional
diagnostic information, they will arrange a private channel.

## Community support scope

Community support covers the open-source CLI, its documented public API, and
its examples. It does not include guarantees for the hosted service,
third-party extensions, or unverified integrations.

Questions are answered on a best-effort basis. Security reports follow the
process in [SECURITY.md](SECURITY.md).
